CatatanSkrip 03–07 berdiri sendiri

Tiap skrip mengulang bagian setup-nya, jadi Anda bisa mulai dari mana saja tanpa harus menjalankan skrip sebelumnya. Pengulangan ini disengaja: peserta yang tertinggal bisa langsung mengejar, dan skrip yang dibuka kembali enam bulan lagi tetap jalan sendiri.

Cara memakai

  1. Klik tautan di atas — berkasnya terbuka sebagai teks biasa
  2. Pilih semua (Ctrl/Cmd + A), lalu salin
  3. Di Code Editor: Scripts → NEW → File, beri nama, tempel
  4. Ubah bagian AOI ke wilayah Anda
  5. Klik Run
TipUbah satu hal saja pada percobaan pertama

Ganti AOI-nya lebih dulu, jalankan, pastikan berhasil. Baru setelah itu ubah tahun, kelas, atau band. Kalau semuanya diubah sekaligus lalu muncul error, tidak ada cara tahu bagian mana yang salah.

Repositori Earth Engine

Supaya peserta tidak perlu menyalin satu per satu, seluruh skrip juga akan dibagikan sebagai repositori Earth Engine — cukup satu klik untuk membuka semuanya di Code Editor Anda.

Tautannya akan ditambahkan di sini sebelum hari pertama, dan berbentuk:

https://code.earthengine.google.com/?accept_repo=users/<nama>/webinar-gee
PeringatanRepositori bersifat baca-saja

Anda bisa membuka dan menjalankan, tetapi perubahan Anda tidak tersimpan di sana. Simpan salinan Anda sendiri lewat Scripts → NEW → File sebelum mulai mengubah, atau pekerjaan Anda hilang saat menutup tab.

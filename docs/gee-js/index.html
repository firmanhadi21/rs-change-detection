1 · Kenapa Earth Engine 20 menit

Mulai dengan pertanyaan ke peserta: kalau ingin melihat perubahan tutupan lahan satu kabupaten selama sepuluh tahun, apa yang harus dilakukan?

Jawaban cara lama: cari citra di katalog, unduh satu per satu, tiap scene ratusan MB, koreksi atmosfer, mozaik, potong, baru analisis. Untuk sepuluh tahun satu kabupaten itu bisa ratusan gigabyte dan berminggu-minggu kerja — sebelum satu pun kesimpulan lahir.

Earth Engine membalik urutannya. Datanya tidak pindah ke Anda; kode Anda yang pindah ke datanya. Seluruh arsip Landsat sejak 1984, Sentinel sejak 2015, MODIS sejak 2000, ditambah ratusan dataset lain, sudah duduk di server Google. Anda menuliskan apa yang ingin dihitung, Google yang mengerjakan, dan yang dikirim balik ke layar Anda hanya gambar petanya.

2 · Tur Code Editor 20 menit

Sekilas layarnya padat, tetapi hanya ada empat bagian yang perlu dikenali.

Kiri — Scripts / Docs / Assets Scripts menyimpan skrip Anda. Docs adalah dokumentasi lengkap semua fungsi — ini yang paling sering dilupakan pemula, padahal isinya jawaban dari 90% pertanyaan. Assets untuk data Anda sendiri.
Tengah — Editor kode Tempat mengetik. Run menjalankan seluruh skrip dari atas ke bawah. Save menyimpan. Get Link membuat URL berisi skrip Anda — cara terbaik membagikan pekerjaan ke rekan atau dosen pembimbing.
Kanan — Console / Inspector / Tasks Console menampilkan hasil print(). Inspector membaca nilai piksel saat Anda mengklik peta — alat debug paling berguna di GEE. Tasks tempat ekspor dijalankan.
Bawah — Peta Setiap Map.addLayer() menambah satu lapisan. Panel Layers di pojok kanan atas mengatur transparansi dan mematikan lapisan — sangat membantu saat membandingkan sebelum/sesudah.
Dua kebiasaan yang menghemat berjam-jam Inspector adalah cara tercepat memeriksa "apakah nilainya masuk akal". Klik di laut, lihat NDVI-nya negatif — berarti perhitungan Anda benar.

Tasks sering terlupakan. Export di dalam skrip tidak langsung mengekspor; ia hanya mengantre. Anda masih harus klik RUN di tab Tasks. Peserta yang bilang "ekspornya tidak jalan" hampir selalu lupa ini.

4 · Klien vs server 40 menit

Bagian terpenting seluruh webinar Kalau dari empat jam ini hanya satu hal yang diingat peserta, buat itu bagian ini. Hampir semua kebingungan pemula di GEE berakar di sini — dan tidak satupun bisa dipecahkan dengan menyalin skrip orang lain.

Ada dua dunia yang hidup berdampingan di dalam satu skrip:

Klien (peramban Anda)Server (Google)
Contohvar a = 5;var b = ee.Number(5);
CiriJavaScript biasaSelalu diawali ee.
Dihitung diLaptop AndaData center Google
Boleh pakai if/for?BolehTidak

Kenapa if tidak boleh dipakai pada objek server

Contoh ini yang paling jelas menunjukkannya. Jalankan sendiri:

var b = ee.Number(1);

if (b.gt(3)) {
  print('lebih besar dari 3');   // ini TETAP tercetak!
}

Padahal 1 jelas tidak lebih besar dari 3. Kenapa tetap tercetak?

Karena b.gt(3) tidak mengembalikan true atau false. Ia mengembalikan sebuah objek ee.Number — perintah yang belum dijalankan, yang baru akan dievaluasi di server nanti. Dan di JavaScript, objek apa pun dianggap "benar". Jadi blok if itu selalu jalan, apa pun isinya.

Ini bukan bug. Ini konsekuensi dari kenyataan bahwa peramban Anda belum tahu nilainya — dan tidak akan tahu sampai server menghitungnya.

Hal yang sama berlaku untuk perulangan

// SALAH — for-loop tidak bisa menyentuh isi ImageCollection
for (var i = 0; i < koleksi.size(); i++) { ... }

// BENAR — .map() menyuruh server melakukannya untuk setiap citra
var hasil = koleksi.map(function (citra) {
  return citra.normalizedDifference(['B8', 'B4']);
});

.map() adalah cara Earth Engine berkata "kerjakan fungsi ini pada setiap elemen, di sisimu, secara paralel". Untuk ribuan citra, bedanya bukan soal gaya penulisan — for memang tidak akan berhasil sama sekali.

⚠ getInfo() — pakai sehemat mungkin getInfo() memaksa hasil dari server pindah ke peramban sekarang juga, dan peramban membeku sampai selesai. 
print(koleksi.size());              // benar — print menanganinya secara asinkron
var n = koleksi.size().getInfo();   // jalan, tapi memblokir; hindari kecuali perlu
Jangan pernah memakainya di dalam .map().
Tugas hari 1 · 10 menit a. Ubah ee.Number(1) pada contoh if menjadi ee.Number(5). Apakah hasilnya berubah? Kenapa tidak?
b. Tampilkan satu citra Sentinel-2 di wilayah Anda, lalu klik Inspector dan klik satu titik di peta.
c. Di Console, buka segitiga di sebelah print(citra) dan telusuri isinya. Ada berapa band? Kapan citra itu direkam?

Kalau (c) terasa membingungkan, itu wajar — dan itu justru inti hari pertama: yang dicetak bukan gambar, melainkan deskripsi tentang gambar.

5 · Komposit bebas awan 20 menit

Satu citra jarang cukup di Indonesia, dan pesertanya biasanya sudah tahu alasannya sebelum kita menyebutkannya: awan. Menunggu satu citra yang benar-benar bersih di atas Sulawesi bisa berarti menunggu berbulan-bulan.

Solusinya bukan mencari citra sempurna, melainkan menggabungkan banyak citra tidak sempurna. Untuk setiap piksel: buang yang tertutup awan, lalu ambil nilai tengah (median) dari sisanya. Awan di citra A ditambal piksel bersih dari citra F — otomatis, per piksel.

// Area kerja — ganti ke wilayah Anda
var area = ee.Geometry.Rectangle([121.90, -3.30, 122.05, -3.15]);
Map.centerObject(area, 12);

// Membuang piksel awan dengan band SCL (Scene Classification Layer)
function maskAwan (citra) {
  var scl = citra.select('SCL');
  var bersih = scl.neq(3)        // 3  = bayangan awan
        .and(scl.neq(8))         // 8  = awan probabilitas sedang
        .and(scl.neq(9))         // 9  = awan probabilitas tinggi
        .and(scl.neq(10))        // 10 = cirrus tipis
        .and(scl.neq(11));       // 11 = salju / es
  return citra.updateMask(bersih);
}

// Satu komposit median untuk satu rentang tanggal
function komposit (mulai, selesai) {
  return ee.ImageCollection('COPERNICUS/S2_SR_HARMONIZED')
    .filterBounds(area)
    .filterDate(mulai, selesai)
    .filter(ee.Filter.lte('CLOUDY_PIXEL_PERCENTAGE', 60))
    .map(maskAwan)
    .median();
}

var sebelum = komposit('2023-01-01', '2023-12-31');
var sesudah = komposit('2026-01-01', '2026-06-30');

Map.addLayer(sebelum.clip(area), {bands:['B4','B3','B2'], min:0, max:3000}, 'Sebelum 2023');
Map.addLayer(sesudah.clip(area), {bands:['B4','B3','B2'], min:0, max:3000}, 'Sesudah 2026');

Jalankan, lalu bandingkan kedua lapisan dengan menyalakan–mematikannya lewat panel Layers. Perbedaannya seharusnya sudah terlihat dengan mata telanjang.

Kenapa max: 3000, bukan 255? Sentinel-2 Level-2A menyimpan pantulan permukaan dalam bilangan bulat yang dikalikan 10.000. Jadi nilai 3000 berarti pantulan 0,30 alias 30% — kira-kira batas atas yang wajar untuk vegetasi dan tanah. Kalau citra tampak terlalu gelap, naikkan; terlalu terang, turunkan.

Tambahkan juga versi warna semu, lalu nyalakan bergantian:

Map.addLayer(sesudah.clip(area), {bands:['B8','B4','B3'], min:0, max:3000}, 'Warna semu');

Pada warna semu, vegetasi sehat menyala merah terang — karena daun memantulkan inframerah-dekat jauh lebih kuat daripada cahaya tampak. Sifat inilah yang dipakai NDVI di bagian berikutnya.

7 · Klasifikasi tutupan lahan 30 menit

NDVI memberi tahu seberapa hijau. Klasifikasi memberi tahu apa — hutan, tambang, air, terbangun — dan itu yang biasanya diminta dalam laporan.

Langkah 1 · Siapkan band

Menambahkan indeks hampir selalu menaikkan akurasi, karena air dan lahan terbuka jadi lebih mudah dibedakan dari vegetasi.

var citra = sesudah.select(['B2','B3','B4','B8','B11','B12'])
  .addBands(ndvi(sesudah))
  .addBands(sesudah.normalizedDifference(['B3','B8']).rename('NDWI'))
  .addBands(sesudah.normalizedDifference(['B11','B8']).rename('NDBI'))
  .clip(area);

Langkah 2 · Gambar titik latih — bagian yang tidak bisa disalin

Komputer tidak tahu seperti apa "tambang" di wilayah Anda. Anda yang memberi tahu.

Di panel Geometry Imports (kiri atas peta): klik + new layer, ganti namanya, klik ikon roda gigi → Import as: FeatureCollection, tambahkan property kelas berisi angka. Lalu gambar 20–40 titik di area yang jelas kelas itu.

Mulai dari sedikit kelas. Lima kelas yang benar jauh lebih berguna daripada dua belas kelas yang saling tertukar.

Langkah 3 · Bagi 70/30, latih, uji

var contoh = citra.sampleRegions({
  collection: titikLatih, properties: ['kelas'], scale: 10, tileScale: 2
});

var acak = contoh.randomColumn('acak', 42);
var latih = acak.filter(ee.Filter.lt('acak', 0.7));    // 70% melatih
var uji   = acak.filter(ee.Filter.gte('acak', 0.7));   // 30% menguji

var model = ee.Classifier.smileRandomForest(100)
  .train({features: latih, classProperty: 'kelas',
          inputProperties: citra.bandNames()});

var hasil = citra.classify(model);
Map.addLayer(hasil, {min:0, max:4,
  palette:['1f4e79','1a7d3a','9acd32','c0392b','d9b38c']}, 'Tutupan lahan');

Langkah 4 · Baca akurasinya sebelum melihat petanya

var matriks = uji.classify(model).errorMatrix('kelas', 'classification');
print('Overall accuracy:', matriks.accuracy());
print('Kappa:', matriks.kappa());
print('Confusion matrix:', matriks);
Peta klasifikasi selalu terlihat meyakinkan Apa pun yang Anda masukkan, hasilnya berupa peta berwarna rapi yang terlihat profesional. Itu sebabnya pembagian 70/30 tidak boleh dilewati.

Kalau model diuji dengan titik yang sama seperti yang dipakai melatih, akurasinya hampir selalu tinggi — persis seperti murid yang sudah diberi bocoran soal. Angka itu tidak berarti apa-apa.

Kalau rendah, lihat confusion matrix: baris yang nilainya tersebar menunjukkan kelas mana tertukar dengan apa. Yang paling sering di Indonesia: pertanian tertukar dengan lahan terbuka, karena sawah bera secara spektral memang mirip tanah kosong.

⚠ Di sinilah kuota itu terasa Kalau muncul "User memory limit exceeded", inilah batas yang disebut kemarin. Tiga cara mengatasinya, dari yang paling ringan: naikkan tileScale (2 → 4 → 8), perkecil AOI, atau naikkan scale dari 10 ke 20 selagi masih bereksperimen.

8 · Deteksi perubahan 25 menit

var selisih = ndviSesudah.subtract(ndviSebelum);

Map.addLayer(selisih, {min:-0.3, max:0.3,
  palette:['#b2182b','#f7f7f7','#1a9850']}, 'Perubahan NDVI');

var AMBANG = -0.15;              // turun lebih dari 0,15 dianggap kehilangan
var hilang = selisih.lt(AMBANG);

Map.addLayer(hilang.selfMask().clip(area), {palette:['red']}, 'Kehilangan vegetasi');

.selfMask() menyembunyikan piksel bernilai nol, sehingga yang tergambar hanya area yang benar-benar berubah.

Lalu ubah peta menjadi angka — bagian yang biasanya paling ditunggu:

var luas = hilang.multiply(ee.Image.pixelArea())   // luas tiap piksel, m2
  .divide(10000)                                    // m2 -> hektar
  .reduceRegion({
    reducer: ee.Reducer.sum(), geometry: area,
    scale: 20, maxPixels: 1e10
  });

print('Luas kehilangan vegetasi (ha):', luas);

reduceRegion meringkas seluruh piksel dalam sebuah wilayah menjadi satu angka. Parameter scale menentukan resolusi perhitungan, dan berpengaruh besar pada waktu proses; untuk latihan 20 m sudah memadai.

Angka −0,15 itu pilihan, bukan kebenaran Tidak ada yang menurunkannya dari langit. Ubah menjadi −0,10 dan area merah melebar; −0,25 dan ia menyempit.

Karena itu, saat melaporkan hasil, selalu sebutkan ambang yang dipakai. Pernyataan "wilayah A dua kali wilayah B pada ambang yang sama" jauh lebih kokoh daripada "wilayah A rusak 37,2%".

Untuk pemateri — hasil yang seharusnya muncul

Tidak ada yang keliru, tidak ada bug. Yang berubah cuma satu keputusan yang biasanya tidak pernah disebutkan dalam laporan.

Kalau angka peserta meleset agak jauh dari tabel ini, penyebabnya kemungkinan besar arsip yang bertambah — citra 2026 masih terus masuk — bukan kesalahan pengetikan.

Setelah webinar

  1. Jalankan ulang untuk wilayah Anda minggu ini juga, selagi masih ingat. Menunda sebulan berarti mengulang dari nol.
  2. Ganti satu hal, lihat akibatnya. Ubah tahunnya, kelasnya, ambang batasnya. Memahami datang dari mengubah, bukan dari menjalankan.
  3. Simpan skrip Anda lewat Scripts → NEW → File, dan pakai Get Link untuk membagikannya.

Kalau ada yang tidak berjalan, bawa pesan error persisnya — pesan itu hampir selalu menunjukkan baris yang bermasalah, dan sebagian besar sudah pernah ditanyakan orang lain di EE Developers Group.

**VO (EN)** — Fifteen scenarios need this account. Not because somebody has not

saat data itu muncul di sana, skenarionya ikut pindah dan Anda tidak perlu
mengubah apa pun.

**VO (EN)** — That is a catalogue limit, not an unfinished port. If that data

## 3 · 02:00–04:40 · Registering, and making a key

**SCREEN** — Browser, screen recording. Move deliberately; pause on each page
long enough to read.

**NOTE** — **The console UI moves.** Do not narrate button positions or exact
menu labels — narrate what you are *looking for*, so the episode survives the
next redesign. If a page looks different by the time a viewer follows along,
they should still know what they need.

**VO (ID)** — Tiga hal yang Anda cari, apa pun tampilan halamannya saat Anda
menonton ini.

**VO (EN)** — Three things you are looking for, whatever the pages look like when
you watch this.

**VO (ID)** — Satu: **daftarkan penggunaan Anda di Earth Engine**, dan pilih
kategori yang benar. Untuk instansi pemerintah, kampus, dan LSM, penggunaan
nonkomersial biasanya gratis. Jangan asal pilih — kategori inilah yang menentukan
apakah Anda ditagih.

**VO (EN)** — One: **register your use of Earth Engine**, and choose the right
category. For government agencies, universities and NGOs, non-commercial use is
normally free. Do not guess here — this category is what decides whether you are
billed.

**VO (ID)** — Dua: **buat proyek Google Cloud**, lalu hubungkan ke Earth Engine.
Catat ID proyeknya.

**VO (EN)** — Two: **create a Google Cloud project**, then link it to Earth
Engine. Note the project ID.

**VO (ID)** — Tiga: di dalam proyek itu, buat **service account**, lalu buat
**kunci JSON** untuknya dan unduh. Berkas itulah yang dibaca `earthchange`.

**VO (EN)** — Three: inside that project, create a **service account**, then
create a **JSON key** for it and download it. That file is what `earthchange`
reads.

**SCREEN** — The downloaded JSON open in an editor, with the private key blurred.
Point at `client_email`.

**VO (ID)** — Ini isinya. Bidang `client_email` itu identitas service account
Anda — sebentar lagi akan muncul di terminal. Sisanya rahasia.

**VO (EN)** — This is what is inside. The `client_email` field is your service
account's identity — it will appear in your terminal shortly. The rest is
secret.

**LOWER-3** — `Kunci JSON = kata sandi. Jangan pernah masuk git.`

**VO (ID)** — Dan sekali lagi, karena ini betul-betul terjadi pada orang: berkas
ini setara kata sandi. Jangan dikirim lewat WhatsApp, jangan ditaruh di dalam
folder proyek yang Anda commit ke git.

**VO (EN)** — And once more, because this genuinely happens to people: this file
is a password. Do not send it over WhatsApp, and do not leave it inside a project
folder you commit to git.

## 4 · 04:40–06:45 · Three places to put it

**SCREEN** — Card listing the three, numbered, in priority order.

**VO (ID)** — Ada tiga cara memberitahukan letak kunci itu, dan dicoba dalam
urutan ini.

**VO (EN)** — There are three ways to tell it where the key is, and they are
tried in this order.

**VO (ID)** — Pertama, langsung di perintahnya:

**VO (EN)** — First, on the command itself:

**TYPE**
```bash
earthchange -s fire-danger --admin Ketapang --date 2026-08-02 \
  --ee-key ~/keys/ee-geodetic.json
```

**VO (ID)** — Berguna kalau Anda punya beberapa kunci, atau sedang menguji milik
orang lain. Merepotkan kalau harus diketik tiap kali.

**VO (EN)** — Useful if you hold several keys, or you are testing somebody
else's. Tedious if you have to type it every time.

**VO (ID)** — Kedua, lewat variabel lingkungan. Ini yang paling saya sarankan,
karena berlaku dari direktori mana pun:

**VO (EN)** — Second, an environment variable. This is the one I recommend,
because it works from any directory:

**TYPE**
```bash
export EARTHCHANGE_EE_KEY=~/keys/ee-geodetic.json
```

**VO (ID)** — Taruh baris itu di `.bashrc` atau `.zshrc` Anda, sekali, dan
selesai.

**VO (EN)** — Put that line in your `.bashrc` or `.zshrc`, once, and you are
done.

**VO (ID)** — Ketiga, letak bawaan. Salin kuncinya ke sini dengan nama persis
ini, dan ia ditemukan tanpa flag dan tanpa variabel:

**VO (EN)** — Third, the default location. Copy the key here, with exactly this
name, and it is found with no flag and no variable:

**TYPE**
```bash
mkdir -p ~/.config/earthengine
cp ~/Downloads/my-key.json ~/.config/earthengine/ee-geodetic.json
```

**NOTE** — The filename is not a suggestion. `ee-geodetic.json` is the literal
name looked for at that path. Say it slowly, and put it on screen.

**LOWER-3** — `~/.config/earthengine/ee-geodetic.json  — nama berkas harus persis`

**VO (ID)** — Ada cara keempat, `earthengine authenticate`, yang memakai akun
Google pribadi Anda lewat peramban. Itu berfungsi, dan untuk ekspor ke Google
Drive dengan `--drive` itu justru **wajib** — karena service account mengekspor
ke Drive miliknya sendiri, yang tidak bisa Anda buka. Untuk pekerjaan sehari-hari,
tetap pakai service account: tidak kedaluwarsa saat Anda tidak melihat.

**VO (EN)** — There is a fourth way, `earthengine authenticate`, which uses your
personal Google account through a browser. It works, and for exporting to Google
Drive with `--drive` it is **required** — because a service account exports to
its own Drive, which you cannot open. For everyday work stay with the service
account: it does not expire while you are not looking.

## 5 · 06:45–07:45 · The line that tells you it worked

**SCREEN** — Terminal. Run any small Earth Engine scenario. Freeze on the first
line of output.

**OUTPUT** ✓ *(verbatim form)*
```
GEE: service account earthchange@my-project.iam.gserviceaccount.com  [/Users/…/ee-geodetic.json]
```

**VO (ID)** — Baris ini, di awal tiap run yang memakai Earth Engine. Ia
menyebutkan **service account mana** dan **berkas kunci mana** yang benar-benar
dipakai.

**VO (EN)** — This line, at the top of every Earth Engine run. It names **which
service account** and **which key file** was actually used.

**VO (ID)** — Baca sekali. Kalau Anda punya dua kunci — satu untuk proyek yang
ditagih dan satu tidak — baris inilah yang memberi tahu Anda sedang memakai yang
mana, sebelum tagihannya yang memberi tahu.

**VO (EN)** — Read it once. If you hold two keys — one on a billed project and
one not — this line tells you which one you are on, before the invoice does.

## 6 · 07:45–09:00 · There is no automatic fallback

**SCREEN** — Card: an arrow from *Earth Engine* to *MPC*, crossed out.

**VO (ID)** — Pertanyaan yang sering muncul: kalau kredensial Earth Engine tidak
ada, apakah paketnya otomatis pindah ke Planetary Computer?

**VO (EN)** — A question that comes up often: if Earth Engine credentials are
missing, does the package fall back to Planetary Computer automatically?

**VO (ID)** — **Tidak.** Dan itu disengaja.

**VO (EN)** — **No.** And that is deliberate.

**VO (ID)** — Peralihan diam-diam berarti Anda menjalankan perintah yang sama,
mendapat peta yang tampak sama, tapi dari katalog, masker awan, dan grid yang
berbeda — dan tidak ada apa pun di layar yang memberi tahu Anda. Enam bulan
kemudian Anda membandingkan dua run dan selisihnya bukan perubahan lahan, tapi
perbedaan backend. Anda tidak akan bisa memisahkannya lagi.

**VO (EN)** — A silent switch means you run the same command, get a map that
looks the same, but from a different catalogue, a different cloud mask and a
different grid — with nothing on screen to tell you. Six months later you compare
two runs and the difference is not land-cover change, it is the backend. You will
not be able to separate them again.

**VO (ID)** — Jadi kalau butuh MPC, Anda mengetikkannya. Kalau butuh Earth
Engine dan kuncinya tidak ada, ia berhenti dan bilang begitu. Selalu ada
tepat satu jawaban untuk pertanyaan "peta ini dari mana".

**VO (EN)** — So if you want MPC, you type it. If it needs Earth Engine and the
key is missing, it stops and says so. There is always exactly one answer to the
question "where did this map come from".

**LOWER-3** — `Tidak ada peralihan diam-diam. Ia berhenti dan memberi tahu.`

## 7 · 09:00–10:00 · Verify with the smallest possible run

**SCREEN** — Terminal.

**VO (ID)** — Jangan uji kredensial dengan analisis besar. Uji dengan yang
paling kecil, supaya kalau gagal Anda tahu penyebabnya kredensial dan bukan yang
lain.

**VO (EN)** — Do not test credentials with a big analysis. Test with the smallest
one, so that if it fails you know the cause is credentials and nothing else.

**TYPE**
```bash
earthchange -s fire-danger --lat -1.7 --lon 110.5 --radius 10 -n cek \
  --date 2026-08-02 --spinup 15
```

**VO (ID)** — Radius sepuluh kilometer, spinup lima belas hari. Hasilnya tidak
punya arti ilmiah — dan memang tidak dimaksudkan begitu. Yang kita uji cuma satu:
apakah baris `GEE: service account` muncul, dan apakah ada berkas keluaran.

**VO (EN)** — Ten-kilometre radius, fifteen days of spin-up. The result is not
scientifically meaningful — and is not meant to be. We are testing one thing:
does the `GEE: service account` line appear, and is there an output file.

**VO (ID)** — Kalau iya, kredensial Anda beres, dan Anda tidak akan menyentuh
episode ini lagi. Berikutnya kita pakai — dan kita mulai dari pertanyaan yang
membuat paket ini dibangun: seberapa berbahaya kondisinya hari ini.

**VO (EN)** — If it does, your credentials are done and you will never touch this
episode again. Next we use them — starting with the question this package was
built around: how dangerous are conditions today.

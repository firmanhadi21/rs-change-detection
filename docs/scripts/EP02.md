# Episode 2 · An animation of the fires burning right now
### *Animasi kebakaran yang sedang berlangsung*

**Runtime** 12:00 · **Prerequisite** EP01 · **Account** none · **Install** `pip` + `ffmpeg`

**Aim** — Produce a shareable video of the current fire season in one command.

**Deliverable** — An MP4 and a GIF of the viewer's own region, ready to post.

## 2 · 00:35–02:05 · Install

**SCREEN** — Empty terminal, fresh shell.

**VO (ID)** — Dua hal yang dipasang. Pertama paketnya, dengan tambahan `video`.

**VO (EN)** — Two things to install. First the package, with the `video` extra.

**TYPE**
```bash
pip install 'earthchange[video]'
```

**NOTE** — Hold on the tail of the pip output. Do not speed it up; say out loud
how long it took. The extra pulls a 3-D renderer and it is not a small install.

**VO (ID)** — Tanda kutipnya wajib. Tanpa kutip, shell membaca tanda kurung siku
sebagai pola nama berkas dan Anda akan dapat pesan error yang membingungkan.

**VO (EN)** — The quotes matter. Without them the shell reads the square

**VO (ID)** — Kedua, `ffmpeg`. Ini bukan paket Python; ia yang merangkai
gambar-gambar jadi video.

**VO (EN)** — Second, `ffmpeg`. This is not a Python package; it is what turns
the frames into a video.

**TYPE**
```bash
brew install ffmpeg        # macOS
sudo apt install ffmpeg    # Ubuntu / Debian
```

**TYPE**


**VO (ID)** — Kalau baris ini menjawab, Anda siap. Kalau tidak, tidak akan ada
berkas MP4 di ujung sana — kerangkanya jadi, videonya tidak.

**VO (EN)** — If that answers, you are ready. If it does not, there will be no

## 3 · 02:05–03:20 · The smallest command that works

**SCREEN** — Terminal. Type it as one line first, then reformat with backslashes
so the viewer sees both forms.

**TYPE**
```bash
earthchange -s smoke-video --lat -7.942 --lon 112.65 --radius 120 -n Bromo
```

**VO (ID)** — Itu saja. Titik tengah, radius dalam kilometer, nama untuk berkas
keluaran. Tidak ada tanggal — dan sebentar lagi kita bahas kenapa tidak ada
tanggal.

**VO (EN)** — That is the whole thing. A centre point, a radius in kilometres, a
name for the output. There is no date — and in a moment we will talk about why
there is no date.

**SCREEN** — Press enter. Let it start. Progress lines appear.

**NOTE** — This run takes minutes, not seconds: it downloads a terrain tile,
renders a basemap, fetches ninety-odd aerosol frames and encodes twice. **Do
not cut away and come back to a finished file.** Talk over the wait — scene 4 is
written to fill exactly this gap — and say the true duration.

**CUT TO:**

---

## 4 · 03:20–05:25 · What it is doing while you wait

**SCREEN** — Split: the running terminal on the left, `GFX` build on the right
stacking three layers as each is named.

**VO (ID)** — Tiga lapis, dari tiga sumber yang berbeda.

**VO (EN)** — Three layers, from three different sources.

**VO (ID)** — Paling bawah, **medan**. Data ketinggian, dirender jadi bayangan
bukit tiga dimensi. Ini yang membuat gunungnya terlihat sebagai gunung, bukan
sebagai tambalan warna.

**VO (EN)** — At the bottom, **terrain**. Elevation data, rendered as a
three-dimensional hillshade. This is what makes a mountain read as a mountain
instead of a coloured patch.

**VO (ID)** — Di tengah, **asap** — dari CAMS, model atmosfer global Eropa. Ini
yang bergerak.

**VO (EN)** — In the middle, **smoke** — from CAMS, the European global
atmosphere model. This is the layer that moves.

**VO (ID)** — Paling atas, **titik api** dari FIRMS: deteksi termal satelit
NASA. Titik-titik yang muncul dan memudar itu bukan hiasan; tiap satu adalah
piksel yang terbaca panas pada hari itu.

**VO (EN)** — On top, **fire detections** from FIRMS: NASA's satellite thermal
detections. Those markers appearing and fading are not decoration; each one is a
pixel that read hot on that day.

**LOWER-3** — `Medan + CAMS (asap) + FIRMS (titik panas)`

**NOTE** — Do not call FIRMS detections "fires" in narration here. Episode 12
spends a whole segment on why a detection is a pixel-day. Say "deteksi" /
"detections" now and buy that segment its punchline.

**VO (ID)** — Perhatikan resolusi asapnya. CAMS sekitar 44 kilometer per sel.
Itu lebih kasar daripada kebanyakan kabupaten. Anda bisa memperkecil radius
sampai 20 kilometer, dan asapnya tidak akan bertambah detail — yang bertambah
cuma interpolasinya.

**VO (EN)** — Note the resolution of the smoke. CAMS is about 44 kilometres per
cell. That is coarser than most districts. You can shrink the radius to 20
kilometres and the smoke gains no detail — all you gain is interpolation.

**LOWER-3** — `CAMS ≈ 44 km/sel — memperkecil radius tidak menambah detail asap`

## 5 · 05:25–06:55 · The result — and why it cannot show 2015

**SCREEN** — File manager on the output folder. Point at the MP4, the GIF, the
frames directory. Open the MP4.

**VO (ID)** — MP4 untuk diunggah, GIF untuk ditempel di WhatsApp atau di dalam
laporan.

**VO (EN)** — An MP4 to upload, a GIF to drop into WhatsApp or into a report.

**SCREEN** — Cut to a card: a seven-day window sliding along a calendar.

**VO (ID)** — Sekarang soal tanggal. Umpan publik FIRMS itu **tujuh hari
berjalan**. Bukan arsip — jendela. Yang ada di sana hanya tujuh hari terakhir,
dan hari kedelapan hilang.

**VO (EN)** — Now, the date. The FIRMS public feed is a **rolling seven days**.
Not an archive — a window. It holds the last seven days, and the eighth day is
gone.

**VO (ID)** — Dua akibatnya. Yang baik: ini satu-satunya skenario yang bisa
menjangkau kemarin. Semua yang lain di seri ini tertinggal berhari-hari sampai
berbulan-bulan. Yang buruk: skenario ini **tidak akan pernah** bisa menampilkan
musim 2015, atau 2019, atau bulan lalu. Bukan opsi yang belum ditambahkan —
datanya memang tidak ada lagi di umpan itu.

**VO (EN)** — Two consequences. The good one: this is the only scenario here
that reaches yesterday. Everything else in this series runs days to months
behind. The bad one: this scenario can **never** show the 2015 season, or 2019,
or last month. That is not a missing option — the data is simply no longer in
that feed.

**LOWER-3** — `FIRMS umpan publik = 7 hari berjalan · tidak ada arsip`

**NOTE** — This is the honest reason there is no `--date` flag, and it is worth
being blunt about. A viewer who expects to animate 2015 and finds out in month
three will not trust the rest.

## 6 · 06:55–09:25 · Labels — putting the names where they belong

**SCREEN** — Two stills side by side: the default output, and the labelled one.
The difference should be obvious without narration.

**VO (ID)** — Versi pertama tadi benar, tapi belum bisa diserahkan ke siapa
pun. Tidak ada yang tahu itu daerah mana. Nama tempat Anda pasang sendiri.

**VO (EN)** — That first version is correct, but it is not yet something you can
hand to anyone. Nobody knows where it is. You place the names yourself.

**TYPE**
```bash
earthchange -s smoke-video --lat -7.942 --lon 112.65 --radius 120 -n Bromo \
  --video-title "WILDFIRE SMOKE" \
  --video-subtitle "GUNUNG BROMO · JAWA TIMUR · {period} · CAMS + VIIRS" \
  --video-cities "BROMO,112.953,-7.942,major; Malang,112.632,-7.981,major; Probolinggo,113.216,-7.754" \
  --video-labels "TENGGER,112.98,-7.75,major; SEMERU,112.922,-8.13,major"
```

**VO (ID)** — Formatnya `nama, bujur, lintang`, dipisah titik koma. Tambahkan
`major` kalau labelnya ingin lebih besar. `--video-cities` untuk permukiman,
`--video-labels` untuk bentang alam — gunung, pegunungan, teluk.

**VO (EN)** — The format is `name, longitude, latitude`, separated by
semicolons. Add `major` for a larger label. `--video-cities` for settlements,
`--video-labels` for landforms — mountains, ranges, bays.

**VO (ID)** — Bujur dulu, baru lintang. Kebalikan dari urutan yang Anda pakai
sehari-hari. Kalau labelnya mendarat di laut, kemungkinan besar itu sebabnya.

**VO (EN)** — Longitude first, then latitude. The reverse of the order you say
out loud. If your label lands in the sea, that is almost always why.

**LOWER-3** — `nama,bujur,lintang[,major]  —  bujur dulu`

**VO (ID)** — Kenapa tidak dicari otomatis? Karena pencari nama otomatis akan
menaruh "Malang" di titik tengah wilayah administrasinya, bukan di tempat yang
enak dibaca di peta Anda, dan ia tidak tahu label mana yang penting. Yang tahu
Anda.

**VO (EN)** — Why not look them up automatically? Because an automatic geocoder
puts "Malang" at the centroid of its administrative area, not where it reads
well on your map, and it has no idea which labels matter. You do.

**SCREEN** — Now the composition note. Show the earlier Bromo frame where the
summit sits under the overlay panel, then the corrected one.

**VO (ID)** — Dan satu soal komposisi. Titik tengah run ini **bukan** puncak
Bromo — puncaknya di 112,95, titik tengahnya 112,65, tiga persepuluh derajat ke
barat. Digeser sengaja, karena pada versi pertama gunungnya tepat berada di
bawah panel infografis. Titik tengah menentukan bingkai, bukan subjek.

**VO (EN)** — And one on composition. This run's centre is **not** Bromo's
summit — the summit is at 112.95, the centre is 112.65, three-tenths of a degree
west. It was moved deliberately, because in the first version the mountain sat
directly under the infographic panel. The centre point sets the frame, not the
subject.

**LOWER-3** — `Titik tengah = bingkai, bukan subjek`

## 7 · 09:25–10:55 · When the terrain comes out black

**SCREEN** — The known black-terrain frame, full screen. Hold on it — this is a
real failure a colleague hit, not a hypothetical.

**VO (ID)** — Kalau medannya keluar hitam pekat seperti ini, jangan diulang
berkali-kali berharap berubah. Penyebabnya satu: perender tiga dimensi tidak
menemukan perangkat grafis yang bisa dipakai.

**VO (EN)** — If your terrain comes out solid black like this, do not just run
it again hoping it changes. There is one cause: the 3-D renderer found no
graphics device it could use.

**VO (ID)** — Ini lazim di server, di mesin virtual, dan di sebagian laptop.
Paketnya mendeteksi kerangka hitam itu sendiri, lalu beralih ke perhitungan
bayangan bukit di CPU — dan memberi tahu Anda bahwa ia melakukannya.

**VO (EN)** — This is common on servers, on virtual machines, and on some
laptops. The package detects the black frame itself, falls back to a CPU
hillshade — and tells you it has done so.

**SCREEN** — Point at the `terrain_source.txt` line in the output folder.

**VO (ID)** — Sumber medan yang benar-benar dipakai dicatat di berkas ini. Kalau
Anda ragu peta yang mana yang Anda pegang, di situ jawabannya.

**VO (EN)** — The terrain source actually used is recorded in this file. If you
are ever unsure which one you are holding, that is where the answer is.

**VO (ID)** — Hasil CPU sedikit lebih datar, dan itu wajar. Yang tidak wajar
adalah kerangka hitam yang lolos sampai ke video jadi.

**VO (EN)** — The CPU result is a little flatter, and that is fine. What is not
fine is a black frame surviving into a finished video.

## 8 · 10:55–12:00 · Now do your own

**SCREEN** — Terminal, blank command with the coordinates highlighted.

**VO (ID)** — Ganti dua angka jadi wilayah Anda sendiri, dan jalankan. Kalau

**VO (EN)** — Change two numbers to your own area and run it. If you do not know

**VO (ID)** — Kalau lokasi Anda di luar Asia Tenggara, satu tambahan:

**VO (EN)** — If you are outside Southeast Asia, one extra flag:
`--firms-region`, because the FIRMS feed is split by continent.

**VO (ID)** — Dan kalau ruang penyimpanan menipis — tiap run meninggalkan
ratusan kerangka gambar mentah:

**VO (EN)** — And if disk space gets tight — each run leaves hundreds of raw
frames behind:

**TYPE**
```bash
earthchange -s smoke-video --video-clean ...
```

**VO (ID)** — Episode berikutnya kita berhenti melihat dan mulai mengukur:
deteksi perubahan tutupan lahan, tetap tanpa akun.

**VO (EN)** — Next episode we stop looking and start measuring: land-cover
